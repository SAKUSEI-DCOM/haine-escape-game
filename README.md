# 12時間監禁脱出ゲーム

## ファイル
- `host.html`：這音さん用サイト
- `listener.html`：リスナー用サイト
- `config.js`：Firebase設定（必ず書き換え）
- `firestore.rules`：Firestoreルールの試作
- `assets/`：提供画像5枚

## 公開手順
1. Firebase Consoleでプロジェクトを新規作成。
2. Authentication > Sign-in method で「匿名」を有効にする。
3. Firestore Databaseを作成し、`firestore.rules` の内容をルール画面に貼って公開。
4. プロジェクト設定 > ウェブアプリ追加 でFirebase設定値を取得し、`config.js` の `REPLACE_ME` を置換する。
5. `escape12` フォルダの中身をGitHub PagesまたはFirebase HostingでHTTPS公開する（`file://` では動きません）。
6. `https://公開URL/host.html` と `https://公開URL/listener.html` が別URLになります。

## 操作
這音さん：`host.html` → ゲームを始める → `0219` → 4桁コードを発行 → プロローグ → 監禁部屋に進む。
リスナー：`listener.html` → コードと名前 → 注意・説明 → 了承して参加。

## 大事な注意
- これは動作確認向けの試作です。入室パスワード `0219` と正解 `Vm12251110` はJavaScript内にあり、ブラウザの開発者ツールで読めます。**本番の秘密管理にはCloud Functionsなどサーバー側での検証が必要です。**
- 参加者が同時に救済・妨害する処理はFirestoreトランザクションで管理していますが、ルールは本番向けの完全な不正対策ではありません。
- 妨害のサンバは著作権フリーの簡易シンセ音で代用しています。ブラウザの自動再生制限により音が鳴らない場合があります。実際の音源を使う場合は使用許諾のある音源を用意してください。
- タイマーは共有開始時刻を基準に表示します。端末の時計が大きくずれると表示に差が出ます。厳密な12時間判定にはサーバー時刻を使用してください。
- 失敗時は仮の結果画面を表示します。成功時も仮の脱出画面です。後で差し替えできます。
- リスナーのクールダウンはFirebase匿名アカウント単位です。別端末やブラウザデータ消去による回避を完全には防げません。

## 脱出成功後のメッセージページ
- 正解すると這音さん用・リスナー用の両サイトで同じ脱出成功ストーリーに進みます。
- 「メッセージを確認する」を押すとカード一覧が表示されます。
- 初期カード①はナスカさんからのメッセージです。
- **カード追加方法**：`messages.js` の `messageCards` 配列に `{from:'送り主',text:'メッセージ本文'}` を追加してください。HTMLの編集は不要です。
- 公開後にメッセージを追加する場合は `messages.js` を更新して再公開します。すでにページを開いている人には再読み込みが必要です。
